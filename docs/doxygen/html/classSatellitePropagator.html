Detailed Description

SGP4 orbital propagator, pass window predictor, and link-budget analyzer exposed to QML.

Wraps libsgp4 to compute live sub-satellite coordinates, ground tracks, multi-station visibility windows, joint SNR/FSPL profiles, maximum AMC code rate ($r_{\max}$), and YAML session plans.

Computes maximum achievable code rate $r_{\max}$ for Adaptive Coding & Modulation (AMC).
