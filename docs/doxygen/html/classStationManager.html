Detailed Description

Central persistence, RF parameter calculation, and JSON serialization manager exposed to QML.

Manages three persistent data domains under the application data directory (QStandardPaths::AppDataLocation or portable subdirectories next to the executable):

  • Ground Stations (stations/<stationId>.json + stations.json)
  • Satellites (satellites/<satId>.json + satellites.json)
  • History Sessions (history/<sessionId>/session.json, satellite.json, telemetry.json, stations/<stationId>.json)
