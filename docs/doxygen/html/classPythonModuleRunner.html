Detailed Description

Asynchronous external Python runner for RF attenuation factor and correlation modules.

Discovers Python environments (preferring workspace .venv), manages recent factor .py and correlation .xlsx/.py modules, builds JSON input payloads, and executes scripts non-blockingly via QProcess while emitting progress/completion signals to QML.
